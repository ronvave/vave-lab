▶ Pending new scholars — review before adding —

People submitted through the public survey’s “Scholar not on the list?” flow land here for your review — they are not added to the searchable list automatically. Submissions are anonymous (no informant name/email required), so verify each one before approving. Approve adds the scholar to the master list (they become searchable and appear on the progress page). Reject removes the submission.

Paste research insights (keywords + summary)

Paste one or more scholar insight objects here to update data/scholar-insights.json.enc. Format is the same shape you get from the AI-generation pipeline. Names are matched exactly first, then through the alias table, so "Savou, Rusila" and "Savou-Wara, Rusila" both land in the right canonical entry. Existing keys are replaced in place; unknown names are added as new entries.

How to sync your profile changes to the public site

  1. Set up your Google Sheet — Create a sheet with columns matching the CSV export below (name, slug, salutation, village, paternalProvince, institution, institutionUrl, googleScholarUrl, photo).
  2. Fill in a scholar's profile here using the "Edit" button next to each iTaukei author.
  3. Copy the CSV or JSON using the buttons above, then paste into your Google Sheet (or into data/scholar-profiles.json for the local fallback).
  4. Publish the sheet as CSV (File → Share → Publish to web → CSV format) and paste that URL in the Data source section above.
  5. The public page fetches the sheet on every visit, so changes propagate immediately.
