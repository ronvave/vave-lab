Data source

Public database reads scholar profiles from a Google Sheet. Paste the sheet’s URL here — stored in your browser only, not committed to the repo.

Sharing setup: the plain “Anyone with the link — Viewer” setting is not enough — browsers get a sign-in redirect. Instead, open the sheet in Google › File › Share › Publish to web › choose Comma-separated values (.csv) › Publish, then paste that link. The document itself can stay private; “Publish to web” exposes a read-only CSV snapshot.

Used until you set a sheet URL

GitHub upload (optional): paste a Personal Access Token here so dropped profile photos upload directly to img/scholars/ in the repo instead of embedding as base64. Stored in your browser only, never committed.

Create a fine-grained token at github.com/settings/personal-access-tokens/new → Resource owner: ronvave → Repository access: Only select → ronvave/vave-lab → Repository permissions → Contents: Read and write. That’s it — no other scopes needed. Set an expiration you’re comfortable with (e.g. 90 days). Without a token, dropped photos fall back to inline base64 + “Download for repo”.

How to sync your profile changes to the public site

  1. Set up your Google Sheet — Create a sheet with columns matching the CSV export below (name, slug, salutation, village, paternalProvince, institution, institutionUrl, googleScholarUrl, photo).
  2. Fill in a scholar's profile here using the "Edit" button next to each iTaukei author.
  3. Copy the CSV or JSON using the buttons above, then paste into your Google Sheet (or into data/scholar-profiles.json for the local fallback).
  4. Publish the sheet as CSV (File → Share → Publish to web → CSV format) and paste that URL in the Data source section above.
  5. The public page fetches the sheet on every visit, so changes propagate immediately.
