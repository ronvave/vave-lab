# Project preservation rules

Before editing the iTaukei dashboard, scholar sharing, data adapter, mobility
export, or shared chord chart, read `docs/ITAUKEI-CARD-AND-MOBILITY-CONTRACT.md`.
The user requires saved Admin photos and JSON research insights on BOTH Panel F
and shared pre-launch profiles. Master-file authority does not mean discarding
Admin-owned supplementary content. Preserve canonical mobility Scholar IDs.
Run `node tests/itaukei-card-mobility.test.cjs` before deployment, and document
the verified working state in the Master Build and Change-Control Record.
Do not redesign or remove working card features without a user request.
