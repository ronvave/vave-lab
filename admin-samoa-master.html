Samoa Admin has moved

The Samoa Scholar Database admin panel is no longer served from GitHub Pages. It is now hosted inside the Samoa Apps Script web app, gated by Google authentication and restricted to the approved admin account.

No browser secrets. The retired browser-HMAC contract has been removed. This page ships no SHARED_SECRET, window.SAMOA_WRITEBACK_SECRET_HEX, admin password hash, or signing key. All Master Sheet writes execute server-side under the authorized Google identity.

Open Samoa Admin

If the button above does not point to a Google Apps Script /exec URL, the deployment step is not complete yet. See SAMOA-ADMIN-BUILD-NOTES.md for the deployment procedure. Unauthorized visitors reach a "Not authorized" page — no admin surface is exposed to the public.
