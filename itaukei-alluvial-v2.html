Scholar Mobility — Alluvial v2

Interactive Visualization

Where iTaukei scholars did their Master’s → PhD

This alluvial diagram traces every iTaukei (Indigenous Fijian) scholar through all three levels of detail on both sides at once. Left-to-right the six columns read: Master’s region → country → university → PhD university → country → region. Ribbon width is proportional to the number of scholars and each country is given its own colour. See also the three-level toggle version and the chord diagram in the iTaukei Research Database.

Build the chart from your own CSV or Excel file

Scholar mobility CSV or Excel Drag & drop, or click to choose your .csv or .xlsx
UNSD region CSV or Excel optional Only if you want to override the built-in country→region reference
↓ Download CSV template

Your file stays in your browser — nothing is uploaded to a server. CSV and Excel (.xlsx/.xls) files both work; for Excel the first worksheet is used. The scholar file needs the columns m_uni, m_country, p_uni, p_country. Regions are derived automatically from the UNSD reference; you only need the second file to change that mapping. ISO 3-letter country codes are also read from the UNSD file if present.

Source: iTaukei Research Database.
