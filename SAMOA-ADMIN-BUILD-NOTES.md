## Authentication and secrets

- **Admin password hash** — SHA-256 hex of Ron's chosen admin password.
  Ron will provide this in a follow-up turn; the current stub has a
  `PASSWORD_HASH = 'REPLACE_ME'` sentinel that refuses to unlock.
- **Passcode verifier** — PBKDF2-HMAC-SHA256(100k, salt) of
  `VAVELAB_SAMOA_PASSCODE`; hex form goes into
  `js/samoa-db-gate.js`. Value is Samoa-only.
- **Apps Script signing** — HMAC-SHA-256 with `SHARED_SECRET` from
  `apps-script/samoa-master-writeback.gs`. Fresh value per this build.
- **localStorage isolation** — every key uses the `samoalab.*` prefix
  (`samoalab.admin.session`, `samoalab.db.session`, …). No key is shared
  with any other jurisdiction's admin surface.

## Six-dimension geography model

The admin form separates the six geography systems into their own
independent fieldsets (paternal / maternal) — the form MUST NOT auto-
derive a district from a village, or fill an electoral constituency from
a political district. Each field is edited independently, and each
change is validated against the `MAPPING` block in the Apps Script
writeback.

Owner directive (Ron, 2026-08-30): unresolved geography rows are
preserved as visibly unresolved. The admin surface must expose
"Unresolved — awaiting authoritative source" as a legitimate value; it
must never invite the user to guess.

## ALWAYS_CONFIRM fields

The admin surface pops a plain-language warning before submitting a
change to any of these fields even when the current and new values
match:

- `Scholars.Living Status`
- `Scholars.Review Status`
- `Scholars.Roster Tier`
- `Scholars.Inclusion Status`
