Publications by Gender

Interactive Visualization

Publication Mix by Gender

Each figure shows how one gender’s scholarly output divides across five publication types — Master’s theses, PhD theses, journal articles, books, and book chapters. The coloured bands fill each body bottom-to-top and sum to 100 % of that gender’s publications. The two numbers beside each label give the total scholars and total publications for that gender. It forms part of the Samoan Scholarly Research Database.

Your file stays in your browser — nothing is uploaded to a server. CSV and Excel (.xlsx/.xls) both work. Drop in the Samoan Scholar Publications by Gender.xlsx file directly: the page reads the By Gender worksheet automatically. Alternatively, a plain file works with a Type column plus Female and Male count columns, one row per publication type, and optional Scholars rows for the totals.
