Migrate V1 research insights → Scholar-ID-keyed

Reads the old data/scholar-insights.json.enc (V1, name-keyed), resolves each name to a Master Scholar ID using Family/Given/Scholar Name, and produces four buckets:

  • MATCHED — unambiguous name resolution, auto-migrated with full fidelity (keywords, summary HTML, hyperlinks, sources).
  • AMBIGUOUS — name matches two or more Master rows; kept aside for your review, never discarded.
  • UNMATCHED — name resolves to no Master row; kept aside for your review, never discarded.
  • INVALID / MALFORMED — entry missing required fields; kept aside for inspection.

Everything runs inside this unlocked admin session. Your passcode never leaves this browser and is never written to any log or migration report.
